Connect Your AI Agent to Lumina

Complete guide — from zero to insured in 10 minutes. No blockchain knowledge needed.

What You'll Do

You'll set up your AI agent to buy insurance automatically. After this setup (which takes 10 minutes), your agent operates on its own — you just monitor.

Think of it like this: You're giving your AI agent a credit card (API Key) with a spending limit (Approve). The agent decides when to buy insurance based on rules you define.

Step-by-Step Setup

1 Create Your API Key

The API Key is like a password that lets your agent access Lumina. Run this command (replace YOUR_WALLET with your actual wallet address):

curl -X POST https://lumina-protocol-production.up.railway.app/api/v2/keys/create \
  -H "Content-Type: application/json" \
  -d '{"wallet": "YOUR_WALLET_ADDRESS", "label": "my-agent"}'

You'll get back something like:

{"apiKey": "lum_abc123...", "warning": "Save this key securely."}

⚠️ Save this key NOW

The API Key is shown only once. If you lose it, you'll need to create a new one.

2 Approve USDY Spending (Your Spending Limit)

This step tells your USDY tokens: "Lumina is allowed to charge me up to $X." It's like putting a credit card on file with a spending cap.

You control the limit. If you approve $1,000, that's the maximum your agent can spend. You can change or revoke it anytime.

Go to BaseScan and call the approve function:

Contract: 0x12cc5bd1ab02A50285834eaF6eBdc2d95FB42cC9
Function: approve(address, uint256)
  spender: 0x8407aF8a100812bFb5f9f188b44379E4268efF94
  amount:  10000000000  (= $10,000)

Or via command line:

cast send 0x12cc5bd1ab02A50285834eaF6eBdc2d95FB42cC9 \
  "approve(address,uint256)" \
  0x8407aF8a100812bFb5f9f188b44379E4268efF94 \
  10000000000 \
  --rpc-url YOUR_RPC_URL \
  --private-key YOUR_KEY

This is your risk limit. If you approve $10,000, that's the absolute maximum. Your agent can't spend more than that. You can revoke this permission anytime from MetaMask or by setting the approve to 0.

3 Give Your Agent the API Key + SKILL File

Your agent needs two things:

1. The API Key — set it as an environment variable or config:

LUMINA_API_KEY=lum_your_key_here

2. The SKILL File — download it and give it to your agent as context:

Download LUMINA-SKILL.txt →

The SKILL file tells your agent what products exist, how to call the API, when to buy each product, and pricing rules.

4 Test It — Buy Your First Policy

Run this to verify everything works:

curl -X POST https://lumina-protocol-production.up.railway.app/api/v2/purchase \
  -H "Content-Type: application/json" \
  -H "X-API-Key: lum_your_key_here" \
  -d '{"productId":"BSS","coverageAmount":100000000,"durationSeconds":604800}'

This buys a $100 Black Swan Shield for 7 days. If you see "success": true, you're all set!

✔ That's it!

Your agent can now buy insurance on its own. Monitor activity on the Dashboard.

Kill Switch (Emergency Stop)

If something goes wrong, revoke the approve:

Call approve with amount 0 on the USDY contract. This instantly prevents Lumina from charging any more USDY. Your agent won't be able to buy policies until you re-approve.

cast send 0x12cc5bd1ab02A50285834eaF6eBdc2d95FB42cC9 \
  "approve(address,uint256)" \
  0x8407aF8a100812bFb5f9f188b44379E4268efF94 \
  0 \
  --rpc-url YOUR_RPC_URL --private-key YOUR_KEY

You can also revoke from MetaMask → Connected Sites → Revoke Permissions.
