WHAT IS LUMINA?
Lumina Protocol is a parametric insurance platform for AI agents on Base L2.
You can buy insurance policies to protect your portfolio against market crashes, stablecoin depegs, impermanent loss, and smart contract exploits.
You buy policies via a simple HTTP API. No blockchain knowledge needed.

API BASE URL: https://lumina-protocol-production.up.railway.app

AUTHENTICATION: All purchase requests require an API Key header:
X-API-Key: YOUR_API_KEY_HERE

PRODUCTS:
BSS = Black Swan Shield: ETH crashes 30%+, 7-30 days, 20% deductible
DEPEG = Depeg Shield: Stablecoin loses peg, 14-365 days, 10% deductible
IL = IL Index Cover: Impermanent loss in LPs, 14-90 days, 2% deductible
EXPLOIT = Exploit Shield: Smart contract hacks, 90-365 days, 10% deductible

HOW TO BUY (1 HTTP CALL):
POST /api/v2/purchase
Headers: Content-Type: application/json, X-API-Key: YOUR_KEY
Body: {"productId":"BSS","coverageAmount":1000000000,"durationSeconds":1209600}

coverageAmount: 6 decimals. $1,000 = 1000000000. Min $100, Max $100,000
durationSeconds: 7d=604800, 14d=1209600, 30d=2592000, 90d=7776000, 365d=31536000

OTHER ENDPOINTS:
GET /api/v2/health - Check API status
GET /api/v2/products - List products
GET /api/v2/vaults - Vault TVL, utilization, APY
GET /api/v2/policies?buyer=0x... - Your active policies

DECISION GUIDELINES:
Buy BSS when: ETH volatility high, significant ETH exposure, fearful sentiment
Buy DEPEG when: Hold stablecoins, concerns about issuers, regulatory uncertainty
Buy IL when: Providing LP, volatile assets in pool, want to hedge IL
Buy EXPLOIT when: Funds in DeFi protocols, recent hacks, unaudited protocols

PRICING: Dynamic based on vault utilization (Kink Model). Low demand = cheap. High demand = expensive.
RULES: Max 5 purchases/minute. Wallet needs USDY balance + CoverRouter approve.
