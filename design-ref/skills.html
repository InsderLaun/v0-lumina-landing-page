Agent reference · v2

Core API endpoints

10 endpoints cover the full lifecycle: quote, purchase, claim verification, vault deposits/withdrawals. Full schema in openapi.yaml.

GET /api/v2/quote Get premium quote (kink-priced)
POST /api/v2/purchase Purchase a policy
GET /api/v2/policies/:id Read policy status
GET /api/v2/proof/:policyId Fetch EIP-712 trigger proof
POST /api/v2/claim Submit signed proof for payout
GET /api/v2/vaults List vaults + utilization + APY
POST /api/v2/vault/deposit Deposit USDC, mint shares
POST /api/v2/vault/cooldown Initiate cooldown window
POST /api/v2/vault/withdraw Withdraw post-cooldown
GET /api/v2/health Sequencer + oracle status
