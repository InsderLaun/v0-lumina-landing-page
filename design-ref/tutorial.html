Step 01

Connect your wallet

Authenticate your agent

Open the Lumina app and connect a wallet on Base mainnet. The app auto-detects whether you have USDC and sufficient ETH for gas.

Wallet 0x71C7…F39B

Connect wallet

Issue an API key from the agent dashboard. The key is bound to a single wallet address. Use the NonceManager from the SDK to handle sequential transactions.

# Initialize agent import { LuminaClient } from '@lumina-org/sdk'; const lumina = new LuminaClient({ apiKey: process.env.LUMINA_API_KEY, chain: 8453, signer: wallet });
Step 02

Pick a product

Configure auth & nonce

The product picker shows all 7 active shields. Hover any card for the trigger condition, deductible, and base APR. Pick BCS for BTC, EAS for ETH, Depeg for stables, IL Index for LP positions, Exploit for protocol risk, or Flash for <48h windows.

FLASH-BTC-24H
Quick coverage

24h window, BTC asset. Good for hedging around macro events.

BCS · 7d
Catastrophe coverage

7-day shield, triggers if BTC drops >50%.

Set up the nonce manager and rate limit your calls. The protocol enforces session approval: every relayed purchase requires a buyer signature.

// Session approval — buyer must sign const approval = await lumina.signSessionApproval({ spender: relayer.address, expiry: Date.now() + 3600_000, maxAmount: 50_000_000000n // 50K USDC });
EIP-712 typed data. All signed payloads are typed-data, domain-fixed to chainId 8453 + verifying contract. No replay possible.
Step 03

Get a quote

GET /api/v2/quote

Set the coverage amount and duration. The app fetches a quote from the API, calculates the premium using the kink utilization model, and shows the net payout preview side-by-side.

Single GET request returns a fully-priced quote, including kink-multiplier breakdown. Quote is valid for the duration of MAX_PROOF_AGE (30 minutes).

// GET /api/v2/quote const quote = await lumina.quote({ product: 'BTCCAT-001', coverage: 50_000_000000n, // 50K USDC duration: 14 * 86400 // 14 days }); // Response: // { // premium: 398_500000n, // utilization: 0.62, // multiplier: 1.39, // triggerPrice: 25300_00000000n, // netPayout: 38_800_000000n, // validUntil: 1745672400 // }
Step 04

Approve USDC & sign

POST /api/v2/purchase

Two signatures: one to approve USDC for the CoverRouter, one to confirm the purchase. Once mined, the policy NFT lands in your wallet and the vault locks collateral 1:1.

Waiting period. BCS/EAS have a 1h waiting period after purchase (anti-front-running). Depeg has 24h. Exploit has 14 days.

Submit the purchase. The router validates parameters, routes to the correct shield, and returns the policy ID + tx hash. Same exact flow as the human path, just programmatic.

// approve(USDC) → POST /api/v2/purchase await usdc.approve(coverRouter, quote.premium); const policy = await lumina.purchase({ quoteId: quote.id, approval // EIP-712 session sig }); // → policy.id, policy.txHash, policy.expiresAt
Step 05

Wait for trigger or expiry

This part works the same for everyone. The oracle continuously verifies Chainlink prices against the trigger condition. If the condition fires:

// Trigger fired → automatic payout if (price < triggerPrice && now >= waitingPeriodEnd) { // 1. Oracle signs EIP-712 PriceProof // 2. Anyone calls Shield.claim(proof, policyId) // 3. Vault transfers USDC payout to policyholder // 4. 3% fee goes to Protocol Fee Receiver }

In the app, you'll see a "Triggered" badge on the policy and the payout will land in your wallet within minutes. No claim form, no review.

Subscribe to PolicyManager events via WebSocket. The payout transaction emits ClaimSettled(policyId, payout). If the policy expires clean, collateral returns to the vault automatically.

Why this is different. No human reviews the claim. No DAO vote. No committee. The trigger fires, the proof is signed, the payout executes. End to end: 1 transaction, minutes.
